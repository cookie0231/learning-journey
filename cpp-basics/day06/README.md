# Day 06：结构体设备管理

2026-09-26 编码验收通过，源文件按用户原样上传。

## 文件与功能

- `device.h`：Device 结构体和函数声明。
- `device.cpp`：添加、按编号查找、删除、显示设备。
- `main.cpp`：100 台设备容量的数组、数量和循环菜单。
- 编号必须为正且不重复；状态先读入整数，校验为 0/1 后赋给 bool；删除后元素前移，数量减一。

## 在 Visual Studio 中编译

创建 C++ 空项目，添加 `main.cpp`、`device.cpp` 为 C/C++ 源文件，`device.h` 为 C/C++ 标头。两个源文件必须共同参与生成。

当前验证环境为 MSVC v145、Debug x64，控制台代码页为 936。项目属性 → C/C++ → 命令行 → 其他选项：

```text
/source-charset:utf-8 /execution-charset:.936
```

生成后运行，输入菜单选项；设备名称暂不含空格。

## 实际运行测试

以下八组均通过，进程正常退出：

1. 空数组显示、查询、删除均有提示。
2. 添加在线和离线设备，显示全部并按编号查询，成员正确。
3. 重复编号、0 和负数编号被拒绝，设备数量不增加。
4. 状态输入 2、-1 后要求重新输入，输入 1 后保存为在线。
5. 删除第一台后能查询剩余设备；删除最后一台后显示为空。
6. 删除中间设备后，两侧设备仍完整保留。
7. 查询、删除不存在编号时提示，现有设备保持不变。
8. 添加 100 台后拒绝再添加；删除一台后允许加入新设备，查询成功。
